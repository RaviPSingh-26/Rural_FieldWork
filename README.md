# Rural Fieldwork

Materials from a rural fieldwork study: a master data workbook and two written reports.

## Files
| File | Description |
|---|---|
| `MasterWorkbook 1.xlsx` | Master workbook with the fieldwork data and analysis |
| `Comparative Study of PMJAY and Other govt. schemes in ST households.pdf` | Report comparing PM-JAY (Ayushman Bharat) with other government schemes among Scheduled Tribe households |
| `Measuring Rural Prosperity Through Food Consumption.pdf` | Report on measuring rural prosperity through food consumption |

## Tools
Microsoft Excel for the workbook; reports provided as PDF.
